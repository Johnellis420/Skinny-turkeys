# Skinny Turkeys

A Thanksgiving fasting tracker for one hungry friend group.

- Set a fast by start + end time or start + duration (presets include "Until Thanksgiving dinner")
- A dinner-plate progress ring, time fasted, time left
- What your body is likely doing at each stage of the fast
- Self-deprecating checkpoints that unlock as you go
- "I caved" button, for when the pie wins
- Share your fast as a link so friends run the same start and end time

Everything runs in one `index.html` file. Progress is saved in each person's own browser.

Not medical advice. Drink water, keep electrolytes up, and stop if you feel unwell.
